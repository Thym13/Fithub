# 🏋️‍♂️ Fithub - Fitness & Gym Management Platform

A modern, full-featured fitness and gym management web application developed collaboratively as part of academic coursework and advanced software engineering practices.

## 🚀 Overview

Fithub is designed to connect gym members, trainers, and administrators, offering seamless workout tracking, schedule management, subscription handling, and interactive fitness tools.

## 📂 Repository Structure

- **`Project-Code/`** — The core source code of the web application (React, Vite, TypeScript, Tailwind CSS).
- **`Παραδοτέο 1/`** — Requirements analysis, domain model, and initial specifications.
- **`Παραδοτέο 2/`** — System design, architecture diagrams, and wireframes.
- **`Παραδοτέο 3/`** — Implementation phases and feature integration.
- **`Παραδοτέο 4/`** — Final testing, evaluation, and documentation deliverables.

## 🛠️ Tech Stack (Frontend Application)

- **Framework:** React / Vite (TypeScript)
- **Styling:** Tailwind CSS, shadcn/ui components
- **Package Manager:** pnpm

## ⚙️ Getting Started with Project-Code

1. Navigate to the project code directory:
   ```bash
   cd Project-Code
   ```
2. Install dependencies:
   ```bash
   pnpm install
   ```
3. Run the development server:
   ```bash
   pnpm dev
   ```
